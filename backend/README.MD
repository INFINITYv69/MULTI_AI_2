# 🛡️ Armor — Financial Conversation Intelligence System

> AI-powered multilingual system that detects, transcribes, and analyzes financial conversations in Indian languages.

## 🎯 Problem Statement
Financial decisions in India are discussed informally in Hindi, Hinglish, and regional languages. These conversations are never documented, leading to forgotten commitments and poor financial decisions.

## 💡 Solution
Armor listens to financial conversations, transcribes them in multiple languages, and converts unstructured discussions into structured financial insights using state-of-the-art AI models.

## 🚀 Key Features
- 🎙️ **Real-time audio recording** with live financial keyword detection
- 🌐 **Multilingual STT** using Whisper medium (GPU-accelerated)
- 🤖 **Zero-shot financial classification** using BART-large-MNLI
- 😊 **Multilingual sentiment analysis** using XLM-RoBERTa
- 💡 **Structured insights** using Llama 3.1 70B via Groq
- ✏️ **Editable transcripts** with re-analysis capability
- 📊 **Financial history dashboard** with risk tracking
- 🔒 **Local storage** — all data stays on device
